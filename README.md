# ChemLab AR 🧪

**ChemLab AR: Augmented Reality-Based Chemistry Experiments for Resource-Limited Schools** is an Android mobile application that uses **Augmented Reality (AR), interactive 3D models, and virtual experiments** to make chemistry more accessible and engaging for Senior High School students, particularly in schools with limited laboratory equipment.

The application bridges theoretical chemistry lessons with interactive virtual laboratory experiences. Students can explore **3D Bohr models and molecular structures, simulate flame tests, combine elements, and study curriculum-aligned chemistry lessons** directly from an Android device. The application is designed to function offline, making it suitable for environments with limited or unreliable internet connectivity.

Features

* **Elements** — Interactive periodic table with element information and 3D Bohr model visualization.
* **Burn** — Simulated flame tests using a virtual Bunsen burner and visual flame reactions.
* **Mixing** — Virtually combine elements and visualize resulting compounds through 3D ball-and-stick models.
* **Modules** — 43 structured, curriculum-aligned chemistry lessons.
* **Augmented Reality** — Place and interact with 3D chemistry models in real-world environments.
* **Offline Support** — Periodic table and application data are stored locally for offline use.
* **Interactive Learning** — Designed to help students visualize molecular geometry, bonding, and chemical reactions.

Technologies

* **Unity 3D**
* **C#**
* **ARCore / AR Foundation**
* **Blender**
* **Python**
* **JSON**
* **Android**

Unity serves as the primary development platform, C# handles application logic and interactions, ARCore provides Android AR capabilities, Blender is used for 3D modeling, Python assists with modeling automation, and JSON stores local chemistry data.

Purpose

ChemLab AR was developed to address the lack of accessible laboratory resources in some Philippine schools. By providing virtualized experiments and interactive 3D visualizations, the application aims to give students a safer and more accessible way to connect theoretical chemistry concepts with practical learning experiences.

Academic Project

Developed as a **Bachelor of Science in Information Technology capstone project** at **Pampanga State University, College of Computing Studies**.

The system was evaluated with **3 IT experts and 205 Senior High School students** from Floridablanca National Agricultural School as part of the project's software evaluation.
